# YuCamera 설정 화면 사용 가이드

## 개요

설정 화면은 카메라로 촬영한 사진을 NAS(Network Attached Storage)에 자동 업로드하기 위한 연결 정보를 설정하는 화면입니다.

하단 내비게이션 바의 **설정(⚙)** 탭을 눌러 진입합니다.

---

## 프로토콜 안내

> **이 앱은 HTTP/HTTPS가 아닌 SMB/CIFS 프로토콜을 사용합니다.**
>
> SMB(Server Message Block)는 Windows 공유 폴더, Synology, QNAP 등 NAS 장치가 파일 공유에 사용하는 프로토콜입니다. 웹 브라우저 주소창에 입력하는 `http://...` 형식이 아니므로, HTTP/HTTPS 구분은 해당 없습니다.

---

## 각 항목 설명

### NAS 연결 설정

#### NAS 주소 (필수)

NAS 장치의 IP 주소 또는 호스트명을 입력합니다.

| 형식 | 예시 | 비고 |
|------|------|------|
| IPv4 주소 | `192.168.1.100` | 가장 일반적 |
| 호스트명 | `mynas.local` | mDNS/Bonjour 지원 환경 |
| NetBIOS 이름 | `MYNAS` | Windows 공유 폴더 |

#### 포트 (선택)

SMB 접속에 사용할 포트 번호입니다. **기본값은 445**이며, 비워두면 자동으로 445가 사용됩니다.

| 상황 | 포트 값 |
|------|---------|
| 일반 NAS (Synology, QNAP 등) | `445` (기본값, 생략 가능) |
| 비표준 포트로 설정된 NAS | NAS 설정에서 확인한 포트 번호 입력 |
| 공유기 포트 포워딩 사용 | 외부에서 접속하는 포트 번호 입력 |

> 숫자만 입력할 수 있으며, 최대 5자리(1~65535)까지 입력 가능합니다.

#### 공유 폴더명 — Share Name (필수)

NAS에서 SMB 공유로 설정한 폴더의 **공유 이름**을 입력합니다.
실제 폴더 경로가 아니라 SMB 공유에 붙인 이름입니다.

| NAS 종류 | 확인 방법 |
|----------|-----------|
| Synology | DSM → 제어판 → 공유 폴더 → 이름 열 |
| QNAP | QTS → 제어판 → 공유 폴더 → 공유 이름 열 |
| Windows | 탐색기에서 폴더 우클릭 → 속성 → 공유 탭 → 공유 이름 |

예: NAS에 `photos`라는 공유가 있으면 `photos` 입력

#### 저장 경로 (선택)

공유 폴더 내에서 사진을 저장할 하위 경로입니다.

- 비워두거나 `/`만 입력하면 공유 폴더 최상위에 저장됩니다.
- 입력한 경로가 존재하지 않으면 앱이 자동으로 폴더를 생성합니다.

```
예시:
/mobile/uploads   →  photos 공유 폴더 / mobile / uploads / 사진파일
/2024             →  photos 공유 폴더 / 2024 / 사진파일
(빈칸)            →  photos 공유 폴더 / 사진파일
```

---

### 인증 정보

#### 사용자명 / 비밀번호

NAS 접속 계정을 입력합니다.

- **익명 접속**: 사용자명과 비밀번호를 모두 비워두면 익명(Guest) 접속을 시도합니다.
- 비밀번호 입력란 오른쪽의 눈 아이콘(👁)을 누르면 비밀번호를 확인/숨길 수 있습니다.
- NAS에서 Guest 접속을 허용하지 않는 경우 반드시 계정 정보를 입력해야 합니다.

---

## 설정 저장

**NAS 주소**와 **공유 폴더명**이 모두 입력된 경우에만 **[설정 저장]** 버튼이 활성화됩니다.

저장에 성공하면 `✓ 설정이 저장되었습니다` 메시지가 표시됩니다.

## 연결 요구사항

### 같은 Wi-Fi (일반 사용)

스마트폰과 NAS가 **동일한 Wi-Fi 네트워크**에 있으면 바로 사용할 수 있습니다.

### 외부 네트워크 (LTE/5G)에서 사용

모바일 데이터 환경에서는 아래 방법 중 하나가 필요합니다.

| 방법 | 가능 여부 | 비고 |
|------|-----------|------|
| 포트 포워딩 (포트 445) | 대부분 불가 | 대부분의 통신사가 보안상 포트 445를 차단함 |
| 포트 포워딩 (비표준 포트) | 조건부 가능 | 라우터에서 외부 포트(예: 4445) → 내부 445로 포워딩. 통신사가 해당 포트를 차단하지 않는 경우에만 동작. 앱의 포트 입력란에 외부 포트 번호를 입력 |
| VPN | 가능 (권장) | NAS 또는 라우터의 VPN 서버에 연결 후 사용. 보안상 가장 안전한 방법 |

> **주의**: SMB 프로토콜을 인터넷에 직접 노출하면 보안 위험이 높습니다. 외부 접속이 필요한 경우 VPN 사용을 권장합니다.

## 지원 장치

| 장치 | 비고 |
|------|------|
| Synology NAS | DSM 6.x / 7.x |
| QNAP NAS | QTS 지원 |
| Windows 공유 폴더 | SMB2 이상 |
| 기타 SMB/CIFS 지원 NAS | 동일 방식으로 설정 |

---

## 문제 해결

| 증상 | 확인 사항 |
|------|-----------|
| 업로드 실패 | NAS 주소, 공유 폴더명 철자 확인 |
| 인증 오류 | 사용자명/비밀번호 확인, NAS에서 해당 계정에 공유 폴더 접근 권한 부여 여부 확인 |
| 연결 안 됨 | 스마트폰과 NAS가 같은 Wi-Fi에 있는지 확인, NAS에서 SMB 프로토콜 활성화 여부 확인 |
| 폴더 생성 실패 | NAS 계정에 쓰기 권한이 있는지 확인 |
